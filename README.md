## 🛠️ Local Development

### Prerequisites
- Node.js 18+ or 20+
- npm 9+

### Setup & Run
```bash
# Clone the repository
git clone https://github.com/sarlayash/Forward-Deployment-Engineer-Workshop---Powered-By-Kapil.git

# Navigate into project directory
cd Forward-Deployment-Engineer-Workshop---Powered-By-Kapil

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## 🚢 Deploying to GitHub Pages

This repository includes an automated GitHub Actions deployment workflow in `.github/workflows/deploy.yml`.

1. Go to your repository settings on GitHub: **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `main` or trigger the workflow under the **Actions** tab.
4. Your application will be live at:
   `https://<your-username>.github.io/<repository-name>/`
